## 翻译待办

两套文稿目前是按旧主页拆开的，**还没有逐条校对翻译**。之后改内容时记得：

1. `notes.md` 和 `notes-en.md` 成对更新，不要只改一侧。
2. 新增条目先写原文，再补另一边；标题、目录、日期文案也要对齐。
3. 校对时重点看：漏译、中英混排残留、专有名词不一致、英文书单 / 中文书单是否该出现在对应语言页。
4. 有些段落原本就是单语（如古文、英文原文摘录），拆开后是否保留、如何互译，需要再决定。
